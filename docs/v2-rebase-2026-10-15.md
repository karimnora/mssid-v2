# Rebase V2 sur main — 15 octobre 2026

## État

Les 20 commits V2 ont été rejoués sur main d57f7a0 (V1 Android 1.0.11). La branche main et les déploiements ne sont pas modifiés. Le tag local v2-rebase-backup-20261014-233838 conserve la V2 initiale cfe3a3f. Aucun push forcé n'a été effectué.

## Compatibilité conservée

- Confirmations de sortie, sauvegardes en attente, historique des activités et correctifs V1.
- Choix des profils enfants, carnet parent, compétences et séances V2. Le chargement du compte ne remplace pas le profil enfant sélectionné.
- Mapping commun du profil dans authProfile, utilisé par les connexions, l'inscription, le chargement et le rafraîchissement. Les compétences et séances sont conservées par la file de synchronisation progressSync.
- Récompenses de laboratoire calculées depuis le profil enfant actif ; les totaux du parent ne sont pas recopiés sur l'enfant. Un examen terminé par le parent ne bloque pas sa validation par l'enfant ; les XP ne sont attribués qu'une fois dans ce profil.
- Un carnet inchangé ne déclenche plus une nouvelle notification et une nouvelle synchronisation à chaque passage du délai de sauvegarde.
- Tarifs, quotas, droits, paiement web, API de test et protections Android V2 conservés. Les fichiers de configuration V2 protégés ont été comparés à la sauvegarde initiale.
- Correctifs main de mise en veille Neon conservés : contrôle de vie sans requête SQL et connexions inactives libérées.

## Limites et prochaine validation

Les migrations et le démarrage complet avec une vraie base PostgreSQL V2 doivent être vérifiés dans la CI ou dans la pile de test séparée. Aucun accès à la base de production n'a été utilisé. L'APK natif et les permissions réelles du téléphone restent à tester ; les scénarios navigateur ne remplacent pas ces essais.
